# Раскладка пинов и адресация 1024 каналов

Документ описывает:

- управляющие GPIO ESP32-S3;
- подключение W5500, OLED и энкодера;
- адресацию всех 1024 тестовых контактов через `TCA9548A + MCP23017`;
- формулу перевода `direction/module/pin` в глобальный номер канала.

## 1. GPIO ESP32-S3

### Основная I2C-шина матрицы

| Сигнал | GPIO ESP32-S3 | Назначение |
|---|---:|---|
| SDA | GPIO8 | основная I2C-шина для `TCA9548A` и всех `MCP23017` |
| SCL | GPIO9 | основная I2C-шина для `TCA9548A` и всех `MCP23017` |
| RESET TCA9548A | GPIO4 | аппаратный сброс I2C-мультиплексора |

### Ethernet W5500

| Сигнал | GPIO ESP32-S3 | Назначение |
|---|---:|---|
| MOSI | GPIO11 | SPI TX для W5500 |
| SCK | GPIO12 | SPI clock |
| MISO | GPIO13 | SPI RX для W5500 |
| CS | GPIO10 | выбор микросхемы W5500 |
| RESET | GPIO14 | аппаратный сброс W5500 |
| INT | GPIO15 | линия прерывания W5500 |

### OLED SSD1306

OLED вынесен на отдельный контроллер `Wire1`, чтобы не нагружать шину матрицы.

| Сигнал | GPIO ESP32-S3 | Назначение |
|---|---:|---|
| SDA | GPIO16 | отдельная I2C-шина OLED |
| SCL | GPIO17 | отдельная I2C-шина OLED |

### Энкодер

| Сигнал | GPIO ESP32-S3 | Назначение |
|---|---:|---|
| A / CLK | GPIO18 | канал A энкодера |
| B / DT | GPIO21 | канал B энкодера |
| SW | GPIO47 | кнопка энкодера |

## 2. Структура матрицы 1024 каналов

Матрица строится так:

- 1 x `TCA9548A`
- 8 направлений `D0..D7`
- в каждом направлении 8 микросхем `MCP23017`
- в каждой `MCP23017` по 16 GPIO

Итого:

- `8 направлений x 8 модулей x 16 пинов = 1024 канала`

## 3. Формула глобального номера канала

Каждый тестовый контакт кодируется тремя координатами:

- `direction` — номер ветви `TCA9548A`, `0..7`
- `module` — номер `MCP23017` внутри ветви, `0..7`
- `pin` — номер GPIO внутри `MCP23017`, `0..15`

Формула из прошивки:

```cpp
globalPin = (direction << 7) | (module << 4) | pin;
```

Эквивалентная арифметическая форма:

```text
globalPin = direction * 128 + module * 16 + pin
```

## 4. Нумерация пинов внутри MCP23017

Каждый `MCP23017` даёт 16 контактов:

| Локальный pin | Банк |
|---|---|
| 0..7 | `GPIOA` |
| 8..15 | `GPIOB` |

## 6. Как быстро найти контакт

Примеры:

- `globalPin 0` = `D0 / A0 / GPA0`
- `globalPin 15` = `D0 / A0 / GPB7`
- `globalPin 16` = `D0 / A1 / GPA0`
- `globalPin 127` = `D0 / A7 / GPB7`
- `globalPin 128` = `D1 / A0 / GPA0`
- `globalPin 511` = `D3 / A7 / GPB7`
- `globalPin 1023` = `D7 / A7 / GPB7`

## 7. Обратный расчёт из глобального номера

Если известен только `globalPin`, координаты считаются так:

```text
direction = globalPin / 128
module    = (globalPin % 128) / 16
pin       = globalPin % 16
```

Далее:

- `pin 0..7` => `GPA0..GPA7`
- `pin 8..15` => `GPB0..GPB7`

## 9. DS3231

`DS3231` подключается не к мультиплексору `PCA9548A/TCA9548A` и не к `Wire1`, а к отдельной программной I2C-шине (software I2C).

| Сигнал | GPIO ESP32-S3 | Назначение |
|---|---:|---|
| SDA | GPIO41 | software I2C только для `DS3231` |
| SCL | GPIO42 | software I2C только для `DS3231` |
| VCC | 3.3V | питание `DS3231` |
| GND | GND | общая земля |

Адрес `DS3231`: `0x68`

То есть подключение `DS3231` такое:

- `DS3231 SDA -> GPIO41`
- `DS3231 SCL -> GPIO42`
- `DS3231 VCC -> 3.3V`
- `DS3231 GND -> GND`
