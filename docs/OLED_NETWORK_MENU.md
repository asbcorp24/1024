# GM009605 и асинхронное сетевое меню

## Подключение дисплея GM009605

Проект рассчитан на OLED 0,96 дюйма 128×64 с контроллером SSD1306 и интерфейсом I²C, адрес по умолчанию `0x3C`.

| GM009605 | ESP32-S3 | Назначение |
|---|---:|---|
| VCC | 3V3 | питание 3,3 В |
| GND | GND | общий провод |
| SDA | GPIO16 | отдельная шина `Wire1` |
| SCL | GPIO17 | отдельная шина `Wire1` |

Дисплей нельзя питать от 5 В, если конкретный модуль не имеет собственного стабилизатора и согласования уровней. Безопасный вариант для ESP32-S3 — питание 3,3 В.

OLED специально вынесен на второй аппаратный I²C-контроллер. Основная шина GPIO8/GPIO9 остаётся только для TCA9548A и 64 MCP23017. Поэтому обновление экрана не прерывает измерение матрицы.

## Подключение энкодера

| Энкодер | ESP32-S3 |
|---|---:|
| A / CLK | GPIO18 |
| B / DT | GPIO21 |
| SW | GPIO47 |
| GND / COM | GND |

В коде включены внутренние подтяжки `INPUT_PULLUP`. Для обычного механического энкодера внешние подтягивающие резисторы не обязательны. Если направление вращения оказалось обратным, поменяйте местами выводы A и B.

## Работа меню

Главный экран отображает:

- состояние Ethernet LINK;
- текущий IP;
- режим DHCP или STATIC;
- состояние испытания;
- прогресс измерения.

Нажатие кнопки энкодера открывает `NETWORK MENU`.

Пункты:

1. `DHCP` — включение или отключение DHCP;
2. `IP` — статический IP;
3. `MASK` — маска сети;
4. `GATEWAY` — шлюз;
5. `DNS` — DNS-сервер;
6. `SAVE+REBOOT` — записать параметры в NVS и перезагрузить прибор;
7. `CANCEL` — выйти без сохранения.

При редактировании IPv4:

- вращение изменяет выбранный октет от 0 до 255;
- нажатие переходит к следующему октету;
- после четвёртого октета меню возвращается к списку параметров.

## Асинхронная архитектура

Меню работает в отдельной FreeRTOS-задаче `oled-menu` с низким приоритетом:

- энкодер опрашивается каждые 5 мс;
- дребезг кнопки фильтруется программно;
- OLED обновляется только при изменении состояния или раз в 500 мс на главном экране;
- HTTP, SSE, загрузка файлов и тестовая задача не вызываются из меню;
- сохранение сети выполняется в NVS;
- новые сетевые параметры применяются после программной перезагрузки.

## Значения по умолчанию

```text
DHCP:    ON
IP:      192.168.1.204
MASK:    255.255.255.0
GATEWAY: 192.168.1.1
DNS:     192.168.1.1
```

Все GPIO и значения по умолчанию находятся в `include/AppConfig.h`.
