# Устройство контроля целостности кабельных сборок — 1024 канала

Проект для **ESP32-S3 N16R8**, PlatformIO и Arduino Framework.

Аппаратная матрица состоит из 64 расширителей **MCP23017**:

- 8 направлений, выбираемых через TCA9548A;
- по 8 MCP23017 в каждом направлении;
- адреса MCP23017 в каждой ветви: `0x20…0x27`;
- 16 GPIO на модуль;
- всего 1024 тестовых контакта.

Веб-интерфейс работает через **W5500 Ethernet**. Статика хранится в LittleFS. Эталоны, бинарные матрицы измерений и JSON-отчёты хранятся в отдельном разделе FFat встроенной flash-памяти.

## Реализовано

- инициализация 64 MCP23017 без сторонней библиотеки;
- последовательное чтение `GPIOA + GPIOB` одной I2C-транзакцией;
- I2C 400 кГц;
- полный перебор 1024 выходов `OUTPUT LOW`;
- чтение всей строки матрицы 1024 бита за один проход по 64 модулям;
- исключение диагонали: контакт не сравнивается сам с собой;
- фоновый контроль постоянно низких линий;
- ожидание восстановления отпущенного контакта;
- битовая матрица 1024×1024 размером 128 КиБ в PSRAM;
- сохранение эталонов в `.ref` с заголовком и CRC32;
- сохранение измерений в `.bin` и отчётов в `.json`;
- сравнение: обрывы, паразитные связи, асимметричные измерения;
- веб-интерфейс запуска эталонного и рабочего измерения;
- скачивание файлов через браузер.

## Адрес контакта

```text
DDD AAA PPPP
```

- `DDD` — направление TCA9548A, 0…7;
- `AAA` — адресный номер MCP23017, 0…7;
- `PPPP` — GPIO, 0…15.

```cpp
globalPin = (direction << 7) | (module << 4) | pin;
```

## Пины по умолчанию

### I2C

| Сигнал | ESP32-S3 |
|---|---:|
| SDA | GPIO8 |
| SCL | GPIO9 |
| RESET TCA9548A | GPIO4 |

### W5500

| Сигнал | ESP32-S3 |
|---|---:|
| MOSI | GPIO11 |
| SCK | GPIO12 |
| MISO | GPIO13 |
| CS | GPIO10 |
| RESET | GPIO14 |

Все назначения находятся в `include/AppConfig.h` и должны быть сверены с фактической платой.

## Разделы flash 16 МБ

- два OTA-раздела приложения по 3 МиБ;
- LittleFS 2 МиБ — только HTML, JavaScript и CSS;
- FFat около 8 МиБ — эталоны и результаты;
- coredump 128 КиБ.

Один эталон занимает примерно 128 КиБ плюс заголовок. Одно испытание занимает около 128 КиБ для бинарной матрицы и отдельный JSON-отчёт.

## API

| Метод | URL | Назначение |
|---|---|---|
| GET | `/api/device` | Ethernet, IP и память |
| GET | `/api/status` | состояние текущего теста |
| GET | `/api/references` | список эталонов |
| POST | `/api/reference/capture?name=...` | создать эталон |
| POST | `/api/test/start?reference=file.ref` | проверить кабель |
| GET | `/api/results` | список JSON-отчётов |
| GET | `/api/result?file=result.json` | открыть отчёт |
| GET | `/api/download?type=reference&file=...` | скачать эталон |
| GET | `/api/download?type=result&file=...` | скачать результат |

## Формат эталона

Файл `.ref` содержит:

1. `ReferenceFileHeader`;
2. битовую матрицу размером 131072 байта;
3. CRC32 матрицы хранится в заголовке.

Бит `matrix[source][target] = 1` означает, что при переводе `source` в LOW контакт `target` также был прочитан как LOW. Диагональные биты всегда очищаются.

## Важные аппаратные требования

- MCP23017 и TCA9548A должны работать от 3,3 В вместе с ESP32-S3.
- На основной I2C-шине и на каждой активной ветви нужны корректно рассчитанные подтяжки.
- На каждом MCP23017 нужен блокировочный конденсатор 100 нФ.
- OLAT всех MCP23017 предварительно устанавливается в 0.
- Одновременно TCA9548A открывает только одно направление.
- Перед реальными испытаниями проверить фронты SDA/SCL осциллографом на 400 кГц.
