# Устройство контроля целостности кабельных сборок — 1024 канала

Проект для **ESP32-S3 N16R8**, PlatformIO и Arduino Framework.

Аппаратная матрица состоит из 64 расширителей **MCP23017**:

- 8 направлений, выбираемых через TCA9548A;
- по 8 MCP23017 в каждом направлении;
- адреса MCP23017 в каждой ветви: `0x20…0x27`;
- 16 GPIO на модуль;
- всего 1024 тестовых контакта.

## Асинхронная архитектура

В проекте нет блокирующего цикла обработки HTTP-клиентов.

- W5500 работает через системный драйвер `ETH` ESP32 и общий TCP/IP-стек;
- HTTP работает на `AsyncTCP` и `ESPAsyncWebServer`;
- состояние измерения передаётся браузеру через Server-Sent Events `/api/events`;
- создание эталона, измерение, анализ и сохранение выполняются в отдельной задаче FreeRTOS;
- HTML, JavaScript и CSS отдаются асинхронно из LittleFS;
- загрузка файлов принимается потоковыми частями и записывается во временный файл FFat;
- выгрузка эталонов, матриц и отчётов выполняется потоковой HTTP-отдачей;
- основной `loop()` не обслуживает HTTP и не выполняет измерения.

## Реализовано

- инициализация 64 MCP23017 без сторонней библиотеки;
- последовательное чтение `GPIOA + GPIOB` одной I2C-транзакцией;
- I2C 400 кГц;
- полный перебор 1024 выходов `OUTPUT LOW`;
- чтение всей строки матрицы 1024 бита за один проход по 64 модулям;
- исключение диагонали: контакт не сравнивается сам с собой;
- фоновый контроль постоянно низких линий;
- ожидание восстановления отпущенного контакта;
- битовая матрица 1024×1024 размером 128 КиБ в PSRAM;
- сохранение эталонов в `.ref` с заголовком и CRC32;
- сохранение измерений в `.bin` и отчётов в `.json`;
- сравнение: обрывы, паразитные связи, асимметричные измерения;
- загрузка и выгрузка эталонов через веб-интерфейс;
- загрузка и выгрузка JSON-расчётов и бинарных матриц;
- отображение хода загрузки и измерения без перезагрузки страницы.

## Проверка загружаемых файлов

### Эталон `.ref`

Перед сохранением устройство проверяет:

1. точный размер файла;
2. `magic`, версию формата и число каналов;
3. размер строки и матрицы;
4. CRC32 всей матрицы.

Файл сначала записывается с расширением `.upload`. Только после успешной проверки он атомарно переименовывается в конечный `.ref`.

### Расчёты

- `.bin` принимается только при размере `131072` байта;
- `.json` проверяется синтаксически и должен содержать JSON-объект;
- максимальный размер загружаемого JSON — 1 МиБ;
- незавершённые временные загрузки удаляются при загрузке устройства.

## Адрес контакта

```text
DDD AAA PPPP
```

- `DDD` — направление TCA9548A, 0…7;
- `AAA` — адресный номер MCP23017, 0…7;
- `PPPP` — GPIO, 0…15.

```cpp
globalPin = (direction << 7) | (module << 4) | pin;
```

## Пины по умолчанию

### I2C

| Сигнал | ESP32-S3 |
|---|---:|
| SDA | GPIO8 |
| SCL | GPIO9 |
| RESET TCA9548A | GPIO4 |

### W5500

| Сигнал | ESP32-S3 |
|---|---:|
| MOSI | GPIO11 |
| SCK | GPIO12 |
| MISO | GPIO13 |
| CS | GPIO10 |
| RESET | GPIO14 |
| INT | GPIO15 |

Все назначения находятся в `include/AppConfig.h` и должны быть сверены с фактической платой.

## Сборка и загрузка

```bash
pio run
pio run -t upload
pio run -t uploadfs
pio device monitor
```

После получения адреса по DHCP он выводится в Serial Monitor. При отключённом DHCP используется `192.168.1.204`.

## Разделы flash 16 МБ

- два OTA-раздела приложения по 3 МиБ;
- LittleFS 2 МиБ — только HTML, JavaScript и CSS;
- FFat около 8 МиБ — эталоны, матрицы и расчёты;
- coredump 128 КиБ.

Один эталон занимает примерно 128 КиБ плюс заголовок. Одно испытание обычно создаёт матрицу `.bin` размером 128 КиБ и отдельный JSON-отчёт.

## Формат эталона

Файл `.ref` содержит:

1. `ReferenceFileHeader`;
2. битовую матрицу размером 131072 байта;
3. CRC32 матрицы в заголовке.

Бит `matrix[source][target] = 1` означает, что при переводе `source` в LOW контакт `target` также был прочитан как LOW. Диагональные биты всегда очищаются.

## Важные аппаратные требования

- MCP23017 и TCA9548A должны работать от 3,3 В вместе с ESP32-S3;
- на основной I2C-шине и на каждой активной ветви нужны корректно рассчитанные подтяжки;
- на каждом MCP23017 нужен блокировочный конденсатор 100 нФ;
- OLAT всех MCP23017 предварительно устанавливается в 0;
- одновременно TCA9548A открывает только одно направление;
- перед реальными испытаниями проверить фронты SDA/SCL осциллографом на 400 кГц.
